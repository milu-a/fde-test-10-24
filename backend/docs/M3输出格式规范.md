# M3 输出格式规范（M3 → M4 → M1 接口契约）

> 本规范是分包比选对账管线的**数据契约**：M3 多格式导入的输出、M4 归一匹配的输入/输出，
> 均以本结构为准。样例文件：`data/gc017_quotes.json`（与本规范完全同构，可当模板抄）。
> 校验器：`python tools/validate_quotes.py <你的输出.json>`，退出码 0 即合格。

## 管线位置

```
M3 导入（PDF/Excel/截图 → 原始行） → M4 归一匹配（填 item） → M1 计算引擎（消费）
      └────────── 本规范约束 ──────────┘
```

M3 只负责"读"，不做任何判断性加工；判断性的字段（归一编号、匹配依据）由 M4 回填。

## 顶层结构

```json
{
  "project": "GC-017 园区现场测量与检测",
  "quote_date": "2026-09-18",
  "note": "可选：整体说明",
  "suppliers": {
    "甲": {
      "file": "原始文件相对路径",
      "version": "A-V1 / 2026-09-18",
      "direction": "含税",
      "tax": { ...见下... },
      "stated_total": "40545.00",
      "item_notes": { "C13": "供应商级分项备注（可选）" },
      "lines": [ { ...见下... } ]
    }
  }
}
```

`suppliers` 的键 = 供应商名，数量不限（本项目 4 家，其他项目 3–6 家均可）。

## 供应商级字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `file` | ✅ | 原始文件相对路径 |
| `version` | ⬜ | 供应商报价版本号/日期，照抄表头 |
| `direction` | ✅ | `"含税"` 或 `"未税"`——**供应商级属性**（一家一个口径），依据报价表头判断 |
| `tax.state` | ✅ | `"未声明"` / `"待澄清"` / `"已声明"` / `"已澄清"` 四值枚举 |
| `tax.rate` | 声明时必填 | 字符串，如 `"0.06"`。**state=未声明时不得填任何值**（不得默认补写，规则第二条） |
| `tax.evidence` | 声明时必填 | `{"file": "...", "locator": "..."}`——税率声明的出处 |
| `tax.invoice_type` | ⬜ | `"专票"` / `"普票"` / `null`。未知一律 `null`，不得猜测（影响真实成本口径，M5 用） |
| `tax.at` / `tax.note` | ⬜ | 声明时间 / 表头原文说明 |
| `stated_total` | ⬜ | 原报列示合计，**照抄**（含合计差错也照抄，引擎负责抓错）；无则省略 |
| `item_notes` | ⬜ | `{清单编号: 备注}`，如丙 C13"费用附件未并入主报价" |

## 行级字段（lines[]）

| 字段 | 必填 | 说明 |
|---|---|---|
| `item` | M3 可空 | 统一清单编号（如 `"C03"`）。**M3 允许填 `null`（未匹配）**，由 M4 归一后回填 |
| `name` | ✅ | 供应商原始分项名称，**照抄原文**（异名照抄，如"沉降点观测（建筑物）"） |
| `unit` | ✅ | 原始单位，照抄 |
| `qty` | ✅* | 数字一律**字符串**（`"12"`）；缺失为 `null` |
| `unit_price` | ✅* | 字符串。**行在但单价未填（漏报）→ `null`，禁止写 0**（规则第四条：未知值不当 0） |
| `stated_amount` | ⬜ | 原报列示金额字符串，照抄（含抄写差错也照抄）；未列示为 `null` |
| `source` | ✅ | `{"file": "...", "locator": "..."}`。定位规则：**PDF 标页码+行、Excel 标工作表+行号、图片标条目编码** |
| `note` | ⬜ | 自由文本：异名说明、聊天语境、表头备注等 |

\* 整行缺失的分项：**不输出该行**（M4 拿清单做差集发现漏报）；"行在但单价空"才用 `unit_price: null` 表示。同一分项重复两行 → **照实输出两行**，不要去重（重复由引擎识别）。

## 硬约束（违反即校验失败/返工）

1. **照抄原则**：名称、金额、单位一律照原文，不清洗、不改写、不重算——列示差错是引擎要抓的错误，不是导入端的错误；
2. **数字一律字符串**：`"190.8"` 而非 `190.8`（避免二进制浮点噪声进入计算链）；
3. **未知一律 `null`**：税率、单价、票型未知就是 `null`/`"未声明"`，禁止默认值兜底；
4. **不丢来源**：每行必须有 `source`，否则追溯链断（规则第六条）；
5. **不做判断**：不判断异名归属、不去重、不补漏、不算合计——那些是 M4/引擎的事。

## M4 回填的字段（M3 可忽略）

`item`（清单编号）。M4 另会在 `note` 追加匹配依据（如"异名同范围：对应统一清单C03"）。
重复行标记、漏报占位、税率状态机推进均由引擎/台账层完成，M3/M4 不处理。
