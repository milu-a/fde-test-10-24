# 分包比选工作台 · 前端原型

山南勘测分包比选场景（FDE 企业真题 04「报价各说各话，工程分包怎么比？」）的**纯静态前端界面原型**：无后端、无构建步骤、无公网依赖，双击 `index.html` 或任意静态服务器即可运行。

设计依据：`../比选工作台-前端界面设计文档.md`（界面规格）+ `../ORBISDESIGN(1)/DESIGN.md`（ORBIS Corporate Design 2026）。

## 运行方式

```bash
# 方式一：任意静态服务器（推荐，图片回查功能需 http:// 协议）
cd bizselect-workbench
python -m http.server 8080
# 打开 http://127.0.0.1:8080

# 方式二：直接双击 index.html（多数浏览器可用）
```

## 内置演示主线（GC-017）

1. **首页** → 点击 GC-017 项目卡进入工作区；
2. **② 统一对比台账**（默认 V0 原报）：乙 C08 挂异常红点、C07 标"重复·只计一次"、C09 待确认、C11 缺失；丁 C14 口径不可比；丙 C13 附件未计入；**点击任意金额格 → 回查原件出处**（图片件显示原件截图，Excel/PDF 件显示高亮行表格提取）；
3. **③ 事件与澄清**：CLARIFY-01 / CHANGE-01 事件卡 → **差异预演（dry-run）** → **确认并应用** → 台账重算生成 V1 / V2（版本切换器解锁）；
4. **④ 版本与差异**：V0/V1/V2 时间轴、任意两版本差异表（每行链接到触发事件）、操作记录；
5. **⑤ 导出交付**：导出自检（如实呈现未关闭事项）+ 企业五表模板。

## 红线（界面行为约束）

- 不出现任何"推荐中标 / 综合评分 / 排名"元素；
- 待确认 / 缺失值不入合计、不显示为 0；
- 异常（如乙 C08 超参考区间）只挂线索不改写原值，线索跨版本保留；
- 原件只读，一切修改经由"事件登记 → 人工确认 → 重算 → 新版本另存"并留痕。

## AI 触点说明（按用户要求：大模型 / OCR 均为第三方接口，不做本地部署）

本原型将 AI 能力视为**可插拔的第三方接口调用**，界面上只有两处触点：

1. 收集箱·扫描件/截图识别（丙、丁）——已识别结果缓存于演示数据；
2. 事件与澄清·**AI 提取事件**（路径 B）。

顶栏「模拟第三方接口」开关可切换**离线/在线**：离线时 AI 按钮置灰并提示改走人工登记路径（路径 A），主链路（解析缓存 → 确认 → 计算 → 台账 → 导出）完全可用——对应真实场景"经营敏感数据内网离线处理"的降级设计。

## 已知边界

- 本原型仅为前端界面演示：导出为前端模拟（toast + 历史），登记的人工事件不触发真实重算；
- 其余三个项目（GC-020 / GC-011 / GC-009）为静态卡片，不可进入；
- 数据为课程脱敏虚构数据，来源定位与真实案例文件一一对应。
